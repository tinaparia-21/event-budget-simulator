# 📊 Event Budget Simulator & Scenario Comparison Tool

An interactive, dynamic web-based dashboard built to help event organizers model live variable shifts, overhead costs, mandatory service/tax surcharges, and compare multiple event scenarios side-by-side in real time.

🚀 [Try the Live Interactive App](https://tinaparia-21.github.io/event-budget-simulator/)

---

## ✨ Features

* **Live Variable Control:** Adjust key levers—Guest Count, Variable Cost per Head, Fixed Venue Overhead, and Service/Tax Multipliers—using interactive range sliders.
* **Side-by-Side Comparison:** Model multiple event formats simultaneously (e.g., Campus Gala, Off-Campus Venue, Outdoor Fest) to determine the most cost-effective option.
* **Global Target Budget Cap:** Set a target budget threshold and receive dynamic visual alerts on buffer availability or overruns.
* **No-Backend Required:** Fully responsive client-side web tool running natively in the browser.

## 🛠️ Built With & How It Was Created

This project was prototyped and built collaboratively using **AI-assisted development**:

* **Google Gemini & Gemini Canvas:** Designed the scenario logic, mathematical formulas, and generated the dynamic HTML/CSS/JS web application.
* **HTML5:** Semantic layout and structured components.
* **CSS3:** Modern dark-theme dashboard design.
* **JavaScript (ES6+):** Real-time client-side calculation engine and interactive visual sliders.
* **GitHub Pages:** Automated web hosting and continuous deployment.
